# 最大似然估计

对于一个由参数 θ\thetaθ 驱动的随机事件, 发生nnn次的样本满足独立同分布

Xi∼F(x;θ)X_i\sim F(x;\theta) Xi​∼F(x;θ)

如何基于观测的nnn 个样本的输出，求解对于一个优化度量意义下模型的最优参数 θ^\hat \thetaθ^, 这是优化任务的目标。

似然函数定义为

L(θ∣X1,⋯ ,Xn)=∏i=1f(Xi;θ)L(\theta\mid X_1,\cdots,X_n) = \prod_{i=1} f(X_i;\theta) L(θ∣X1​,⋯,Xn​)=i=1∏​f(Xi​;θ)

θ\thetaθ 的最大似然估计 θ^\hat \thetaθ^ 满足

θ^=arg max⁡θ∏i=1nf(Xi∣θ)\hat{\theta} = \argmax_\theta \prod_{i=1}^nf(X_i\mid \theta) θ^=θargmax​i=1∏n​f(Xi​∣θ)

求导

ln⁡L(θ∣X1,⋯ ,Xn)=∑i=1nln⁡f(Xi;θ)\ln L(\theta|X_1,\cdots,X_n) = \sum_{i=1}^n \ln f(X_i;\theta) lnL(θ∣X1​,⋯,Xn​)=i=1∑n​lnf(Xi​;θ)

∂∂θL(θ∣X1,⋯ ,Xn)=∑i=1nfθ′(Xi;θ)f(Xi,θ)=0\frac{\partial}{\partial \theta}L(\theta|X_1,\cdots,X_n) = \sum_{i=1}^n \frac{f_\theta'(X_i;\theta)}{f(X_i,\theta)} = 0 ∂θ∂​L(θ∣X1​,⋯,Xn​)=i=1∑n​f(Xi​,θ)fθ′​(Xi​;θ)​=0

如果方程存在解且不为边界，则 θ^\hat\thetaθ^ 为最大似然估计，否则可能是满足的边界极值条件。

# 交叉熵和KL散度

概率分布之间的交叉熵定义为

H(p,q):=−∑xpi(x)log⁡qi(x)H(p,q) := -\sum_x p_i(x)\log q_i(x) H(p,q):=−x∑​pi​(x)logqi​(x)

假设有输入分布 pi:Rm→Δnp_i:\mathbb{R}^m\to \Delta^npi​:Rm→Δn 和模型后验输出 p^i:Rm→Δn\hat p_i:\mathbb{R}^m\to\Delta^np^​i​:Rm→Δn, 并且实际的输入分布是one-hot 的, 交叉熵定义为

H(p,p^)=−∑xpi(x;θ)log⁡p^i(x;θ)=−∑xlog⁡p^αi(x;θ)H(p,\hat p) = -\sum_x p_i(x;\theta)\log \hat p_i(x;\theta) = -\sum_x \log \hat p_{\alpha_i}(x;\theta) H(p,p^​)=−x∑​pi​(x;θ)logp^​i​(x;θ)=−x∑​logp^​αi​​(x;θ)

其中 αi\alpha_iαi​ 是真实分类

arg min⁡θH(p,p^)=arg max⁡θ∑xlog⁡p^αi(x;θ)\argmin_{\theta} H(p,\hat p) = \argmax_\theta \sum_x \log \hat p_{\alpha_i}(x;\theta) θargmin​H(p,p^​)=θargmax​x∑​logp^​αi​​(x;θ)

而这正是最大似然估计的极值条件。

# KL散度

H(p,q)=−∑pilog⁡qi=−∑pilog⁡pi+∑pilog⁡piqi=H(p)+∑pilog⁡piqiH(p,q) = - \sum p_i \log q_i =-\sum p_i\log p_i +\sum p_i \log \frac{p_i}{q_i} = H(p)+\sum p_i\log \frac{p_i}{q_i} H(p,q)=−∑pi​logqi​=−∑pi​logpi​+∑pi​logqi​pi​​=H(p)+∑pi​logqi​pi​​

定义KL散度为

DKL(p∥q):=∑pilog⁡piqiD_\mathrm{KL}(p \parallel q) := \sum p_i \log \frac{p_i}{q_i} DKL​(p∥q):=∑pi​logqi​pi​​

KL散度并不符合metric的定义，因为

DKL(p∥q)≠DKL(q∥p)D_\mathrm{KL}(p\parallel q) \neq D_\mathrm{KL}(q\parallel p) DKL​(p∥q)=DKL​(q∥p)

DKL(p∥q)+DKL(q∥r)−DKL(p∥r)=∑(pi−qi)log⁡riqi≱0D_\mathrm{KL}(p\parallel q)+D_\mathrm{KL}(q\parallel r) - D_\mathrm{KL}(p\parallel r) = \sum (p_i-q_i)\log \frac{r_i}{q_i} \not\geq 0 DKL​(p∥q)+DKL​(q∥r)−DKL​(p∥r)=∑(pi​−qi​)logqi​ri​​≥0

对于KL散度的局部扰动，其一阶项消失，二阶项给出局部度量。考虑

H(pθ,pθ+dθ)=−∑ipi(θ)log⁡pi(θ+dθ)=−∑ipi(θ)log⁡[pi(θ)+δpi]=H(pθ)−∑ipi(θ)log⁡[1+pi−1(θ)δpi],\begin{aligned} H(p_\theta,p_{\theta+\mathrm d\theta}) &= - \sum_i p_i(\theta)\log p_i(\theta+\mathrm d\theta) \\ &= - \sum_i p_i(\theta)\log \left[p_i(\theta)+\delta p_i\right]\\ &= H(p_\theta)-\sum_i p_i(\theta)\log\left[1+p_i^{-1}(\theta)\delta p_i\right], \end{aligned} H(pθ​,pθ+dθ​)​=−i∑​pi​(θ)logpi​(θ+dθ)=−i∑​pi​(θ)log[pi​(θ)+δpi​]=H(pθ​)−i∑​pi​(θ)log[1+pi−1​(θ)δpi​],​

其中 δpi:=pi(θ+dθ)−pi(θ)\delta p_i:=p_i(\theta+\mathrm d\theta)-p_i(\theta)δpi​:=pi​(θ+dθ)−pi​(θ)。

因此

DKL(pθ∥pθ+dθ)=−∑ipi(θ)log⁡[1+pi−1(θ)δpi]=−∑iδpi+12∑ipi−1(θ)(δpi)2+o(∥dθ∥2).\begin{aligned} D_\mathrm{KL}(p_\theta\parallel p_{\theta+\mathrm d\theta}) &= - \sum_i p_i(\theta)\log\left[1+p_i^{-1}(\theta)\delta p_i\right] \\ &= -\sum_i\delta p_i+\frac{1}{2}\sum_i p_i^{-1}(\theta)(\delta p_i)^2 +o(\|\mathrm d\theta\|^2). \end{aligned} DKL​(pθ​∥pθ+dθ​)​=−i∑​pi​(θ)log[1+pi−1​(θ)δpi​]=−i∑​δpi​+21​i∑​pi−1​(θ)(δpi​)2+o(∥dθ∥2).​

由于 ∑ipi(θ)=∑ipi(θ+dθ)=1\displaystyle\sum_i p_i(\theta)=\sum_i p_i(\theta+\mathrm d\theta)=1i∑​pi​(θ)=i∑​pi​(θ+dθ)=1，有 ∑iδpi=0\displaystyle\sum_i\delta p_i=0i∑​δpi​=0。又因为

δpi=∇θpi(θ)Tdθ+O(∥dθ∥2),\delta p_i=\nabla_\theta p_i(\theta)^T\mathrm d\theta+O(\|\mathrm d\theta\|^2), δpi​=∇θ​pi​(θ)Tdθ+O(∥dθ∥2),

所以

DKL(pθ∥pθ+dθ)=12dθT[∑ipi−1(θ)∇θpi(θ)∇θpi(θ)T]dθ+o(∥dθ∥2).D_\mathrm{KL}(p_\theta\parallel p_{\theta+\mathrm d\theta}) =\frac{1}{2}\mathrm d\theta^T \left[\sum_i p_i^{-1}(\theta)\nabla_\theta p_i(\theta)\nabla_\theta p_i(\theta)^T\right] \mathrm d\theta+o(\|\mathrm d\theta\|^2). DKL​(pθ​∥pθ+dθ​)=21​dθT[i∑​pi−1​(θ)∇θ​pi​(θ)∇θ​pi​(θ)T]dθ+o(∥dθ∥2).

取 I(θ):=∑ipi−1(θ)∇θpi(θ)∇θpi(θ)TI(\theta):=\sum_i p_i^{-1}(\theta)\nabla_\theta p_i(\theta)\nabla_\theta p_i(\theta)^TI(θ):=∑i​pi−1​(θ)∇θ​pi​(θ)∇θ​pi​(θ)T，即为Fisher 信息矩阵。它是关于 dθ\mathrm d\thetadθ 的半正定二次型；当 I(θ)I(\theta)I(θ) 正定时，它给出局部Riemann度量。
