# GAE

GAE 是一种通过TD渐进估计advantage的方式

compute_gae_advantage_return的实现
单步TD误差

A^t≈δt=rt+γVt+1−Vt \begin{aligned} \hat A_t &\approx \delta_t = r_t+\gamma V_{t+1}-V_t \end{aligned} A^t​​≈δt​=rt​+γVt+1​−Vt​​

A^t(2)=δt+γδt+1\hat A_t^{(2)} = \delta_t+\gamma\delta_{t+1} A^t(2)​=δt​+γδt+1​

A^t(n)=∑k≥0n−1γkδt+k\hat A_t^{( n)} = \sum_{k\geq 0}^{n-1} \gamma^k \delta_{t+k} A^t(n)​=k≥0∑n−1​γkδt+k​

GAE估计定义为TD误差的加权累加符合几何分布

P(N=n)=(1−λ)λnP(N=n) =(1-\lambda)\lambda ^n P(N=n)=(1−λ)λn

则

A^tGAE=EN[A^t(n)]\hat A_t^{GAE} =\mathbb E_N[\hat A_t^{(n)}] A^tGAE​=EN​[A^t(n)​]

A^tGAE=δt+γλA^t+1GAE=δt+∑l≥0(γλ)lA^t+1GAE\begin{aligned} \hat A_t^{GAE} &= \delta_t+\gamma\lambda \hat A_{t+1}^{GAE}\\ & = \delta_t + \sum_{l\geq 0} (\gamma \lambda)^l\hat A_{t+1}^{GAE} \end{aligned} A^tGAE​​=δt​+γλA^t+1GAE​=δt​+l≥0∑​(γλ)lA^t+1GAE​​

在verl的compute_gae_advantage_return 中基于累加实现

for t in reversed(range(gen_len)):
            # 求出delta_t, 等于 r+gamma*V_t - V_{t-1}
            delta = token_level_rewards[:, t] + gamma * nextvalues - values[:, t]
            # 更新 A_t^{GAE}
            lastgaelam_ = delta + gamma * lam * lastgaelam

            # skip values and TD-error on observation tokens
            # 根据response_mask 控制哪些GAE的advantage估计需要保留
            nextvalues = values[:, t] * response_mask[:, t] + (1 - response_mask[:, t]) * nextvalues

            lastgaelam = lastgaelam_ * response_mask[:, t] + (1 - response_mask[:, t]) * lastgaelam

            advantages_reversed.append(lastgaelam)
        advantages = torch.stack(advantages_reversed[::-1], dim=1)

        returns = advantages + values
