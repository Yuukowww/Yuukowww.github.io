# 策略优化算法

自然策略梯度下降的过程可以概括为：

Actor 通过 Rollout 生成动作与 logprob；Critic 利用 Rollout 奖励学习 Value Function，并辅助计算 Advantage；Actor 将 logprob 与 Advantage 结合计算策略梯度，更新策略参数，随后进入下一轮 Rollout。

# KL 散度和二阶计算优化

基于Forward Kl 散度 评估一次策略下降下的误差

DKL(πθ∥πθ+Δθ)=∑x∈Xπθ(x)log⁡πθ(x)πθ+Δθ(x)=−∑x∈X[πθ(x)∂πθ(x)πθ(x)∂θ]TΔθ+O(∥Δθ∥2)=−∑x∈X[∂πθ(x)∂θ]TΔθ+O(∥Δθ∥2)=12ΔθTF(θ)Δθ+o(∥Δθ∥2)\begin{aligned} D_{KL}(\pi_\theta \parallel \pi_{\theta+\Delta \theta}) &= \sum_{x\in X}\pi_\theta(x)\log \frac{\pi_\theta(x)}{\pi_{\theta+\Delta\theta}(x)}\\ & = -\sum_{x\in X} \left[\pi_\theta(x) \frac{\partial \pi_\theta(x)}{\pi_\theta(x)\partial \theta }\right]^T \Delta \theta + O(\|\Delta\theta\|^2) \\ & = -\sum_{x\in X} \left[\frac{\partial \pi_\theta (x)}{\partial\theta}\right]^T\Delta \theta + O(\|\Delta\theta\|^2)\\ & = \frac{1}{2}\Delta\theta^T F(\theta)\Delta \theta +o(\|\Delta\theta\|^2) \end{aligned} DKL​(πθ​∥πθ+Δθ​)​=x∈X∑​πθ​(x)logπθ+Δθ​(x)πθ​(x)​=−x∈X∑​[πθ​(x)πθ​(x)∂θ∂πθ​(x)​]TΔθ+O(∥Δθ∥2)=−x∈X∑​[∂θ∂πθ​(x)​]TΔθ+O(∥Δθ∥2)=21​ΔθTF(θ)Δθ+o(∥Δθ∥2)​

关键问题 具体内容

# Rollout

Rollout 就是基于当前的策略进行一轮采样，并以轨迹 τ\tauτ 生成完整的输出序列。因为有关于当前策略梯度的评估无法通过解析计算，需要通过 Rollout 的样本进行蒙特卡洛近似。

通过Rollout 近似估计的策略单步计算有

  • 策略梯度估计
  • Fisher矩阵估计
  • Advantage / Baseline 估计

∇θJ(θ)=Er∼πθ[R(τ)∇θlog⁡πθ(τ)]⟹∇θJ(θ)≃1m∑k=1mR(τ(k))∇θlog⁡πθ(τ(k))\nabla_\theta J(\theta) = E_{r\sim \pi_{\theta}}[R(\tau)\nabla_\theta\log\pi_\theta(\tau)]\Longrightarrow \nabla_\theta J(\theta) \simeq \frac{1}{m}\sum_{k=1}^m R(\tau^{(k)})\nabla_\theta \log\pi_\theta (\tau^{(k)}) ∇θ​J(θ)=Er∼πθ​​[R(τ)∇θ​logπθ​(τ)]⟹∇θ​J(θ)≃m1​k=1∑m​R(τ(k))∇θ​logπθ​(τ(k))

由于

Eπ∼πθR(τ)=Eτ∼πθold[πθπθoldR(τ)]:=L(θ)E_{\pi\sim \pi_{\theta}} R(\tau) = E_{\tau \sim \pi_{\theta_{old}}}\left[\frac{\pi_\theta}{\pi_{\theta_{old}}}R(\tau)\right]:= L(\theta) Eπ∼πθ​​R(τ)=Eτ∼πθold​​​[πθold​​πθ​​R(τ)]:=L(θ)

取新旧策略比为

r=πθπθoldr = \frac{\pi_\theta}{\pi_{\theta_{old}}} r=πθold​​πθ​​

将期望对象变换为了相对于旧策略的期望，这样就能用旧策略的 rollout 轨迹估计当前策略的目标梯度，在策略未大幅偏移时等价于当前策略目标的真实梯度。

# On-Policy and Off-Policy

On-policy 和 Off-policy是指是否依赖正在优化的策略来产生观测数据。

TRPO/PPO 基于 πold\pi_{old}πold​ rollout的轨迹计算逼近的策略梯度，虽然不等于本轮的策略梯度，但是可以通过IS修正动作差异利用 KL 约束控制策略变化，使得旧策略的状态分布仍能近似代表新策略的状态分布。

典型的Off-Policy 的算法有 DQN/SAC等，通过历史的行为记录训练。

# Critic Networks

Critic Networks 对于当前的策略或者动作进行估计，从而计算更加稳定的策略梯度

V^MC=∑kT−1γkrt+k≃Vϕ(s)\hat{V}^{MC} = \sum_k^{T-1}\gamma^k r_{t+k} \simeq V_\phi(s) V^MC=k∑T−1​γkrt+k​≃Vϕ​(s)

本质上是一个逼近问题，典型的可以通过神经网络优化

  • 输入：Rollout 中的状态 (s_t)
  • 标签：根据奖励构造的 Value Target
  • 输出：Critic 对累计奖励的预测 Vϕ(st)V_\phi(s_t)Vϕ​(st​)
  • 优化器：Adam、SGD 等一阶优化器

Advantage的误差估计中的估计

A^π(st,at)≈rt+γVπ(st+1)−Vπ(st)\hat A^\pi(s_t, a_t)\approx r_t + \gamma V^\pi(s_{t+1}) - V^\pi(s_t) A^π(st​,at​)≈rt​+γVπ(st+1​)−Vπ(st​)
