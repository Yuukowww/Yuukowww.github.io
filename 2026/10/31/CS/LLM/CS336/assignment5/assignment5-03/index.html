# 组内 Reward 归一化

<!-- Test -->
原始GRPO中的组内Reward 存在的问题代码

Rt⟹A^t=Rt−Rˉgσg+εR_t \Longrightarrow \hat A_t = \frac{R_t - \bar R_g}{\sigma_g+\varepsilon} Rt​⟹A^t​=σg​+εRt​−Rˉg​​

Dr.GRPO 中去掉了AtA_tAt​的归一化分母

A~t=Rt−Rˉg\tilde A_t = R_t- \bar R_g A~t​=Rt​−Rˉg​

二元奖励下 R={0,1}R = \left\{0,1\right\}R={0,1}近似两点分布, 期望为 σR2=p(1−p)\sigma_R^2 = p(1-p)σR2​=p(1−p)

A~t=A^tσR,g≈A^tp(1−p)\tilde A_t = \frac{\hat A_t}{\sigma_{R,g}}\approx \frac{\hat A_t}{\sqrt{p(1-p)}} A~t​=σR,g​A^t​​≈p(1−p)​A^t​​

这会导致构建组内的advantage呈现靠近均值低，远离均值高的现象

# 回答长度归一化

Dr.GRPO 考虑将每一个回答的长度均值的改为整体的最大回答长度的均值

LGRPO=−1G∑i=1G1Ti∑t=1Tiℓi,tobj⟶LDr.GRPO=−1GTmax∑i=1G∑t=1Tiℓi,tobjL_{GRPO}= -\frac{1}{G}\sum_{i=1}^G \frac{1}{T_i}\sum_{t=1}^{T_i}\ell_{i,t}^{obj}\longrightarrow L_{Dr.GRPO}= -\frac{1}{GT_{max}}\sum_{i=1}^G \sum_{t=1}^{T_i}\ell_{i,t}^{obj} LGRPO​=−G1​i=1∑G​Ti​1​t=1∑Ti​​ℓi,tobj​⟶LDr.GRPO​=−GTmax​1​i=1∑G​t=1∑Ti​​ℓi,tobj​

避免每一个回答都基于长度计算均值可以降低回答的长度对于每一个token的反向传播的直接缩放
