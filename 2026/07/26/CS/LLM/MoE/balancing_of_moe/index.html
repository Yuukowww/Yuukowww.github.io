φ - Balancing for Mixture of experts traning

MoE 总是倾向于每次Top-k 的 Experts 的负载均衡化.

每一个专家激活概率为 p(x;θ)ip(x;\theta)_ip(x;θ)i​,p(x;θ)=Softmax(Wrx)p(x;\theta) = \mathrm{Softmax}(W_rx)p(x;θ)=Softmax(Wr​x),对应整体激活期望为

pˉ(x;θ)=Ex[p(x;θ)]∈Δn,∑i=1npˉ(x;θ)i=1\bar{p} (x;\theta) = \mathbb{E}_{x} [p(x;\theta)]\in \Delta^n,\qquad \sum_{i=1}^n \bar{p}(x;\theta)_i = 1 pˉ​(x;θ)=Ex​[p(x;θ)]∈Δn,i=1∑n​pˉ​(x;θ)i​=1

选择一个凸的负载优化器 ϕ:Δn→Δn\phi : \Delta^n \to \Delta^nϕ:Δn→Δn 满足

arg min⁡mϕ(m)=(1n,⋯ ,1n)\argmin_m\phi(m) = \left(\frac{1}{n},\cdots, \frac{1}{n}\right) margmin​ϕ(m)=(n1​,⋯,n1​)

以控制负载均衡化

论文中给出了一系列凸优化器函数, 本文声称负Shannon熵实现的任务损失与负载均衡的平衡效果最好

整体优化目标为

min⁡θ[Ltask(θ)+αϕ(θ)]\min_\theta [L_{task}(\theta) +\alpha \phi(\theta)] θmin​[Ltask​(θ)+αϕ(θ)]

LtaskL_{task}Ltask​ 目标是对整体模型的任务优化，ϕ\phiϕ 用于控制模型的负载均衡化，通过超参数 α\alphaα 进行目标侧重的控制。

Fenchel 共轭

Fenchel共轭 定义为

Laux:=ϕ(p)=sup⁡{<p,q>−ϕ∗(q)}L_{aux} := \phi(p) = \sup\left\{\left<p,q\right> - \phi^*(q)\right\} Laux​:=ϕ(p)=sup{⟨p,q⟩−ϕ∗(q)}

单独的均衡化优化为

min⁡θmax⁡q<mθ,q>−ϕ∗(q)\min_\theta \max_q \left<m_\theta,q\right> - \phi^*(q) θmin​qmax​⟨mθ​,q⟩−ϕ∗(q)

比如对于2 experts

m=(θ,1−θ)m = (\theta,1-\theta) m=(θ,1−θ)

假设 LtaskL_{task}Ltask​ 的最优点为 θ=0.6\theta = 0.6θ=0.6 , Balancing 要求 θ=0.5\theta = 0.5θ=0.5

目标优化

J(θ)=(θ−0.8)2+α(θ−0.5)2J(\theta) = (\theta-0.8)^2 + \alpha(\theta-0.5)^2 J(θ)=(θ−0.8)2+α(θ−0.5)2

θ∗=1.6+α2(1+α)\theta^* = \frac{1.6+\alpha}{2(1+\alpha)} θ∗=2(1+α)1.6+α​

lim⁡α→+∞θ∗=lim⁡α→+∞1.6+α2+2α=0.5\lim_{\alpha\to +\infty} \theta^* = \lim_{\alpha\to+\infty}\frac{1.6+\alpha}{2+2\alpha} = 0.5 α→+∞lim​θ∗=α→+∞lim​2+2α1.6+α​=0.5

整体的优化为

min⁡θmax⁡q[Ltask(θ)+α(<mθ,q>−ϕ∗(q))]=min⁡θmax⁡q[Ltask(θ)+α(Ex<p(x;θ),q>−ϕ∗(q))]\min_{\theta}\max_{q}[L_{task}(\theta)+\alpha (\left<m_\theta,q\right>-\phi^*(q))] = \min_{\theta}\max_{q}[L_{task}(\theta)+\alpha (\mathbb{E}_x\left< p(x;\theta),q\right>-\phi^*(q))] θmin​qmax​[Ltask​(θ)+α(⟨mθ​,q⟩−ϕ∗(q))]=θmin​qmax​[Ltask​(θ)+α(Ex​⟨p(x;θ),q⟩−ϕ∗(q))]

Mini-batch 在线优化

取样一个mini-batch， 整体期望可以近似等于取样batch的均值

Ex<p(x;θ),q>≃1∣Bt∣∑x∈Bt<p(x;θt),q>=<pt,q>\mathbb{E}_x\left<p(x;\theta),q\right> \simeq \frac{1}{|B_t|}\sum_{x\in B_t} \left<p(x;\theta_t),q\right> = \left<p_t,q\right> Ex​⟨p(x;θ),q⟩≃∣Bt​∣1​x∈Bt​∑​⟨p(x;θt​),q⟩=⟨pt​,q⟩

对于近似对象

Ft(q)=<pt,q>−ϕ∗(q)F_t(q) = \left<p_t,q \right> - \phi^*(q) Ft​(q)=⟨pt​,q⟩−ϕ∗(q)

∇qFt(q)=pt−∇qϕ∗(qt)\nabla_q F_t(q) = p_t - \nabla_q\phi^*(q_t) ∇q​Ft​(q)=pt​−∇q​ϕ∗(qt​)

取对偶梯度为

mt:=∇ϕ∗(qt)m_t := \nabla \phi^*(q_t) mt​:=∇ϕ∗(qt​)

由Legendre对偶, 有

qt=∇ϕ(mt)q_t = \nabla\phi(m_t) qt​=∇ϕ(mt​)

Mirror-ascent 与 Bregman 距离约束

Single batch 的一次共轭上升对象为

Ft(q)=<pt,q>−ϕ∗(q)F_t(q) = \left<p_t,q\right> - \phi^*(q) Ft​(q)=⟨pt​,q⟩−ϕ∗(q)

对其Taylor展开

Ft(q)≃Ft(qt)+<∇Ft(qt),q−qt>F_t(q) \simeq F_t(q_t) + \left<\nabla F_t(q_t), q-q_t\right> Ft​(q)≃Ft​(qt​)+⟨∇Ft​(qt​),q−qt​⟩

Bregman 距离 作为距离惩罚项，其蕴含起点的平坦性信息与相对竖直距离的大小，在小范围内包含了二阶误差信息, 通过共轭函数生成Bregman距离惩罚

qt+1=arg max⁡q{Ft(qt)+<∇Ft(qt),q−qt>−1ηDϕ∗(q,qt)}=arg max⁡q{<∇Ft(qt),q>−1ηDϕ∗(q,qt)}\begin{aligned} q_{t+1} &= \argmax_q\left\{F_t(q_t) + \left<\nabla F_t(q_t),q-q_t \right> -\frac{1}{\eta} D_{\phi^*}(q,q_t)\right\}\\ & = \argmax_q\left\{\left<\nabla F_t(q_t),q \right> -\frac{1}{\eta} D_{\phi^*}(q,q_t)\right\} \end{aligned} qt+1​​=qargmax​{Ft​(qt​)+⟨∇Ft​(qt​),q−qt​⟩−η1​Dϕ∗​(q,qt​)}=qargmax​{⟨∇Ft​(qt​),q⟩−η1​Dϕ∗​(q,qt​)}​

在最优点 q=qt+1q = q_{t+1}q=qt+1​ 有

∇Ft(qt)−1η[∇ϕ∗(qt+1)−∇ϕ∗(qt)]=0\nabla F_t(q_t) - \frac1\eta \left[ \nabla\phi^*(q_{t+1}) -\nabla\phi^*(q_t) \right] =0 ∇Ft​(qt​)−η1​[∇ϕ∗(qt+1​)−∇ϕ∗(qt​)]=0

即

∇ϕ∗(qt+1)=∇ϕ∗(qt)+η∇Ft(qt)\nabla \phi^*(q_{t+1} ) = \nabla\phi^*(q_t) + \eta \nabla F_t(q_t) ∇ϕ∗(qt+1​)=∇ϕ∗(qt​)+η∇Ft​(qt​)

整个优化动力系统表示为

{mt+1=mt+η(pt−mt)qt=∇ϕ(mt)\begin{dcases} m_{t+1} = m_t + \eta(p_t-m_t)\\ q_t = \nabla \phi(m_t) \end{dcases} {mt+1​=mt​+η(pt​−mt​)qt​=∇ϕ(mt​)​

StopGrad

Laux,t=⟨pt(θ),StopGrad⁡(qt+1)⟩=∑e=1Ept,e(θ)StopGrad⁡(∇ϕ(mt+1)e).L_{\mathrm{aux},t} = \left\langle p_t(\theta), \operatorname{StopGrad}(q_{t+1}) \right\rangle = \sum_{e=1}^{E} p_{t,e}(\theta) \operatorname{StopGrad} \left( \nabla\phi(m_{t+1})_e \right). Laux,t​=⟨pt​(θ),StopGrad(qt+1​)⟩=e=1∑E​pt,e​(θ)StopGrad(∇ϕ(mt+1​)e​).

算法交替进行两个方向的更新：

q-step:固定 θt, 使用 mirror ascent 更新 qt+1,θ-step:固定 qt+1, 对 θ 做梯度下降.\begin{aligned} q\text{-step}:&\quad \text{固定 }\theta_t,\text{ 使用 mirror ascent 更新 }q_{t+1},\\ \theta\text{-step}:&\quad \text{固定 }q_{t+1},\text{ 对 }\theta\text{ 做梯度下降}. \end{aligned} q-step:θ-step:​固定 θt​, 使用 mirror ascent 更新 qt+1​,固定 qt+1​, 对 θ 做梯度下降.​

因此在 θ\thetaθ-step 中需要计算的是关于 θ\thetaθ 的偏导数：

∇θLaux,t=(∂pt∂θ)⊤qt+1.\nabla_\theta L_{\mathrm{aux},t} = \left( \frac{\partial p_t}{\partial\theta} \right)^\top q_{t+1}. ∇θ​Laux,t​=(∂θ∂pt​​)⊤qt+1​.

StopGrad⁡\operatorname{StopGrad}StopGrad 并没有消除 qt+1q_{t+1}qt+1​ 对路由器的影响。它只是阻止梯度继续穿过

pt⟶mt+1⟶qt+1p_t \longrightarrow m_{t+1} \longrightarrow q_{t+1} pt​⟶mt+1​⟶qt+1​

这条对偶更新路径。

qt+1q_{t+1}qt+1​ 仍作为每个 expert 的负载优化梯度：负载较高的 expert 具有更向均衡化的惩罚，最小化 LauxL_{aux}Laux​ 会促使路由器减少分配给这些 expert 的概率。

如果不使用 StopGrad，那么由于

qt+1=∇ϕ((1−η)mt+ηpt),q_{t+1} = \nabla\phi\left((1-\eta)m_t+\eta p_t\right), qt+1​=∇ϕ((1−η)mt​+ηpt​),

梯度还会包含由 qt+1q_{t+1}qt+1​ 对 ptp_tpt​ 的依赖产生的 Hessian 项：

∇pt[pt⊤∇ϕ(mt+1)]=qt+1+η∇2ϕ(mt+1)pt.\nabla_{p_t} \left[ p_t^\top\nabla\phi(m_{t+1}) \right] = q_{t+1} + \eta\nabla^2\phi(m_{t+1})p_t. ∇pt​​[pt⊤​∇ϕ(mt+1​)]=qt+1​+η∇2ϕ(mt+1​)pt​.

若历史状态 mtm_tmt​ 没有被截断，会形成跨训练步不断增长的计算图。

从包络定理也可以理解这一点：若 q∗(θ)q^*(\theta)q∗(θ) 是内层最大化的精确解，则

∇θmax⁡qL(θ,q)=∂θL(θ,q∗(θ)),\nabla_\theta \max_q \mathcal L(\theta,q) = \partial_\theta \mathcal L(\theta,q^*(\theta)), ∇θ​qmax​L(θ,q)=∂θ​L(θ,q∗(θ)),

计算外层梯度时不需要再对 q∗(θ)q^*(\theta)q∗(θ) 关于 θ\thetaθ 求导。论文中的 qt+1q_{t+1}qt+1​ 是对 q∗(θt)q^*(\theta_t)q∗(θt​) 的在线近似，StopGrad 保留了同样的交替优化结构。
