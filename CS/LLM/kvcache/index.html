# KVCache

KV Cache 本质是一个空间换时间的策略

ziz_izi​ 为 token ID，xix_ixi​ 为该位置的投影输入。Prefill 将 prompt 的 xix_ixi​ 按行堆叠为 XXX

Q=XWQ,K=XWK,V=XWV.Q = XW_Q,\qquad K = XW_K,\qquad V = XW_V. Q=XWQ​,K=XWK​,V=XWV​.

由于注意力是单向的，这保证KV可复用且Q每一个token只使用一次。KV Cache 将输入token的KV缓存

qt=xtWQ,kt=xtWK,vt=xtWV.q_t = x_tW_Q,\qquad k_t = x_tW_K,\qquad v_t = x_tW_V. qt​=xt​WQ​,kt​=xt​WK​,vt​=xt​WV​.

沿序列维度更新缓存。

K≤t=[K<tkt]∈Rt×dk,V≤t=[V<tvt]∈Rt×dv.K_{\le t} = \begin{bmatrix}K_{<t}\\ k_t\end{bmatrix} \in\mathbb R^{t\times d_k}, \qquad V_{\le t} = \begin{bmatrix}V_{<t}\\ v_t\end{bmatrix} \in\mathbb R^{t\times d_v}. K≤t​=[K<t​kt​​]∈Rt×dk​,V≤t​=[V<t​vt​​]∈Rt×dv​.

softmax 沿序列维度计算单头注意力输出

ot=Softmax ⁣(qtK≤t⊤dk)⏟1×tV≤t⏟t×dv∈R1×dv.o_t = \underbrace{\mathrm{Softmax}\!\left( \frac{q_t K_{\le t}^{\top}}{\sqrt{d_k}} \right)}_{1\times t} \underbrace{V_{\le t}}_{t\times d_v} \in\mathbb R^{1\times d_v}. ot​=1×tSoftmax(dk​​qt​K≤t⊤​​)​​t×dv​V≤t​​​∈R1×dv​.

hth_tht​ 为位置 ttt 的最终隐藏向量，ℓt\ell_tℓt​ 为词表 logits。

ℓt=htWvocab,p(zt+1∣z1:t)=Softmax(ℓt)zt+1.\ell_t = h_tW_{\mathrm{vocab}},\qquad p(z_{t+1}\mid z_{1:t}) = \mathrm{Softmax}(\ell_t)_{z_{t+1}}. ℓt​=ht​Wvocab​,p(zt+1​∣z1:t​)=Softmax(ℓt​)zt+1​​.
